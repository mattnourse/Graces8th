# Toy Dash to Grace

A single-file HTML5 pixel-art platformer. Run, jump, and dash through three levels to meet Grace at Build-a-Bear, Pizza Express, and the dining table.


## Features

- 3 levels: shopping centre, high street, and toy room
- 8 playable characters (Foz, Oscar, Ananya, Isla, Madison, Beau, Evie, Grace)
- Solo mode or Race vs Tala
- Easy / Medium / Hard difficulty
- Works on iPhone Safari with on-screen touch controls
- Keyboard controls on desktop (arrows / WASD / space)

## Controls

**Mobile:** on-screen LEFT / RIGHT / JUMP buttons
**Desktop:** arrow keys or WASD to move, space / up / W to jump, R to restart

## Run locally

No build step needed. Just open `toy_dash_to_grace_vs_tala.html` in any modern browser.
